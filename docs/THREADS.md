2. 시작 시각과 예상 마감 시각(한국시간)을 적는다.
3. PR 번호는 「🟢 **PR #번호**」로 표시한다.
4. 법률·개인정보·결제 관련 변경은 법률 검토를 먼저 거친다.
5. 대화가 끝나면 `HANDOFF.md` 에 3줄로 결과를 남긴다.
6. 프로젝트 채팅에는 요약만 올린다.
7. 자기 영역 일만 한다. 겹치면 해당 스레드와 조율하고, 정리가 안 되면 C1(사업 판단) 또는 대표에게 올린다.
