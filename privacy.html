개인정보처리방침

시행일: 2026년 10월 30일

입장차이(이하 "운영자")는 자체 콘텐츠를 유튜브와 인스타그램에 게시하고 관리하기 위해 내부용 자동화 도구(이하 "도구")를 사용합니다. 이 방침은 도구가 Google 및 Meta API로 접근하는 정보를 어떻게 다루는지 설명합니다.

1. 도구를 사용하는 사람

도구는 운영자 본인의 계정에서만 사용하며, 일반 이용자를 대상으로 하는 서비스가 아닙니다. 다른 사람의 계정 정보를 수집하지 않습니다.

2. 접근하는 정보와 목적

  • YouTube Data API: 운영자 채널에 영상 업로드, 제목·설명·공개 시각 관리, 재생목록 정리, 운영자 영상의 조회수·댓글 수 확인. 공개 댓글은 다음 회차 대본 기획을 위해 내용을 요약하는 데만 사용하며, 작성자 이름이나 아이디는 저장하거나 공개하지 않습니다.
  • Google Drive API: 도구가 만든 영상 파일을 운영자 드라이브에 보관하고, 인스타그램 게시를 위해 잠시 공유 링크를 만든 뒤 바로 해제합니다.
  • Instagram API: 운영자 계정에 릴스 게시, 운영자 게시물의 조회수·댓글 수 확인.

3. 보관과 보호

인증 정보(토큰)는 운영자 컴퓨터에만 저장되며 외부로 전송하거나 공유하지 않습니다. 수집한 통계는 운영자 컴퓨터의 작업 기록에만 남깁니다.

4. 제3자 제공

어떤 정보도 판매하거나 제3자에게 제공하지 않습니다. Google API에서 받은 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

5. 권한 철회

Google 계정의 보안 › 서드 파티 연결에서 언제든 도구의 접근 권한을 해제할 수 있습니다.
